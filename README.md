# Mood Meter

Tap how you feel; it keeps a small log and a bar chart. React + Vite.

Test project for Olive's upload screen: it should be detected as **React + Vite, web app**
and wait for the runner, because it needs `npm install` and `npm run build` before it can run.

To try it locally (needs Node.js):

```
npm install
npm run dev
```
